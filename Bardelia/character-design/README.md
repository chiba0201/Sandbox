## ナギ

明るい栗色の髪をうなじで無造作に括り、毛先を垂らす。高いポニーテールやお団子にしない。後れ毛あり。長さはほどくと後ろ髪が肩甲骨の上、顔周りが鎖骨ほど。生成りの長袖ブラウスは腕まくりできるゆとりと、腰の後ろの鞘入り小刀を隠せる丈。深い青のズボンは適度な幅。外套は袖付きでがぼっと長く、画像は第三話終盤以降の表が焦げ茶・裏が柘榴色のもの。

## ムジカ

髪に近い明度の明るい灰色のロングコート。髪の艶と服の艶を抑えた布地で違いを出す。前を開け、生成りの襟なしシャツ、内側の布の腰帯、古風でゆとりのあるズボンを見せる。肩の重ね布、立ち襟、葉模様のある袖口。背中は腰を絞らず、身体の線を拾わないがぼっとしたボックスライン。上着側の共布の紐は背中でゆるく垂らし、腰を締めない。内側の太い布帯とは別構造。

灰銀の髪は低い襟足で整えて束ね、前髪は柔らかく残す。周辺の後れ毛を控えて、ナギとの差をつける。風では髪や服は揺れず、本人の動作に伴って揺れる。発光せず、影を落とさない。外見29〜30歳、184cmの精霊。ナギは23歳、163cm。
